# RPM NYC
A new website for RPM NYC to gain reconigition for their oustanding performances and past projects for daily drivers and car enthusiast 
## Technologies
- React
- Typescript
- Tailwind CSS
- Vite
## Features
- Dedicated service page listing out all the unique services that RPM can perform
- A gallery page of all successful car projects
## In Progress
I've been testing out a form submission within the support page of the website for any additional inquiries or service scheduling 
## Running the Project
1. Clone repository
2. Install dependencies: `npm install`
3. Run development server: `npm run dev`
4. Open local host from terminal
